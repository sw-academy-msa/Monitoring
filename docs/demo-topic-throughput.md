# 시연 Kafka 처리량

토픽별 초당 메시지는 broker JMX의 topic 라벨이 있는 MessagesInPerSec Count에 rate를 적용합니다. 해당 토픽의 JMX 시계열이 아직 없으면 기존 kafka exporter의 partition current offset gauge에 deriv[1m]와 clamp_min(0)을 적용한 합계를 사용합니다. broker 전체 합계는 토픽 그래프에 넣지 않습니다. 로그 절단과 리더 변경은 추정치를 왜곡할 수 있습니다.

Canvas의 보라색 연결에서 발행/s는 서비스가 발행하는 토픽의 유입 합계, 커밋/s는 서비스 소비 그룹의 committed offset 전진 추정치입니다. 커밋은 업무 처리 성공이나 메시지 전달 횟수와 다르며, 여러 그룹이 같은 메시지를 읽으면 합계에 각각 포함됩니다. 소비 연결에 생산자 유입 값을 복사하지 않습니다. 기본 그룹 이름과 코드의 토픽 계약을 정적으로 매핑했으므로 환경 변수로 그룹을 변경하면 매핑도 갱신해야 합니다.

0은 흐린 회색, 양수는 보라색으로 표시합니다. 지표 부재는 NaN과 관측 불가로 표시하며 0으로 채우지 않습니다. Kafka 선은 기존 경로를 유지하고 발행과 커밋을 구분하는 방향을 표시합니다. 신규 숫자 요소도 가로와 세로 scale 제약을 사용합니다.

JMX 설정 배포와 broker 적용은 운영 담당자가 수행합니다. 대시보드는 설정 배포 전에 기존 offset으로 동작합니다. 이번 변경에서 운영 재시작이나 배포를 수행하지 않았습니다.
